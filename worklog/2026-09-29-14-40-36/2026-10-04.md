### 缺陷清单第 4 轮：D15 定性更正（重要）

**上一轮把 D15 判成「无错误上报，P2，可带入首发，用户崩溃只能截图」——实测推翻。**

上游把「出问题怎么查」当正经功能做了，覆盖到「界面都加载不出来」这一层：

| 层 | 东西 | 位置 |

| 后端 | `/api/logs/{view}` 三视图 application/backend/setup，tail ≤1.5MB/4000 行 | `app/main.py:839` |
| 后端 | **`/api/logs.zip` 一键打包全部日志** | `app/main.py:898` |
| 日志 | `logs/stemdeck.log`（5MB×3 轮转）/ `backend.log` / `setup.log` | `logging_setup.py:63`、`main.rs:1659` |
| 前端 | **启动失败横幅**——界面加载不出来时自动弹红条，文本可选中复制 | `static/js/boot-diagnostics.js` |
| 前端 | Logs 面板 / 通知面板 | `catalog.js:3968,4007`、`notifications.js:499` |
| 测试 | e2e 专门验证这个横幅存在 | `tests/e2e/boot-failure.spec.mjs` |

**关键机制**：`stemdeck.log` 由 `configure_logging()` 写，而它在 import 之后才跑 →
**后端起不来时它一定是空的**。上游为此专门开了 `backend.log` 视图，
注释原文：*"A backend that dies at startup leaves stemdeck.log empty and the answer here."*

**真正剩下的三个缺口**（都不是「没有上报」）：
1. 横幅给的是**裸路径**不是可点链接，用户得自己拼 `http://127.0.0.1:<port>`；
2. **后端完全起不来时，横幅指的那个地址也不可达**——而横幅恰恰为这个场景设计。
   绕开：直接去数据目录 `logs/` 取 `backend.log`（不依赖后端活着）；
3. **`start.bat` 形态没有 stdout 落盘**（Tauri 壳有 `prepare_backend_stdio` → `backend.log`，
   start.bat 只开控制台窗口，关掉就没了）。**这个口子值得补。**

结论：桌面单机形态**不需要**远程上报。D15 从「中」降「低」，**不再列为拍板项**。
文档已同步：`docs/delivery-defects.md` §四之二 + Obsidian `18_交付缺陷清单.md`。

## 追加：D6 拍板「装到 F 盘」—— 方案与准备（2026-10-04）

**用户拍板**：不装 C 盘，VS Build Tools 全部落 F 盘。

### 关键发现：官方就有路径参数，不必动 Program Files

`vs_installer` 支持 `--path <name>=<path>`，`name` ∈ {install, shared, cache}：

| 参数 | 作用 | 文档原文要点 |
|---|---|---|
| `--path install=` | 主安装目录（等价 `--installPath`，二者只能用一个） | — |
| `--path shared=` | 并行安装的共享文件 | **"Some tools and SDKs install to a location on this drive"** |
| `--path cache=` | 下载缓存 | **仅首次安装可设** |

**⚠️ 但文档同时警告**：*"some others might override this setting and install to another drive"*
→ **不能只靠 shared 参数**，Windows SDK 仍可能硬编码去 C 盘。

### 双保险方案（已准备完毕，待用户执行）

1. 官方 `--path install/shared/cache` 三参数全指 `F:\VSRoot\*`
2. **额外**把 `C:\Program Files (x86)\Windows Kits\10` 预置成 **Junction → `F:\VSRoot\WindowsKits\10`**
   —— 这样即便 SDK 忽略参数写死在 C 路径，实际字节也落在 F 盘

C 盘不可避免的只剩 `Microsoft Visual Studio\Installer\`（安装器本体，~200 MB）。

### ⚠️ 环境约束（本轮踩到）
