## 第二批灰阶收口（commit b58061e）
- 85 个 .vue/.css 文件 1545 处中性灰收敛到语义令牌；4 个 .vue 的 echarts option 17 处用 tc()。
- 关键经验（可复用）：批量换色**必须按 CSS 属性上下文**做，不能全局替换 hex —— 否则侧栏深色背景、渐变、SVG fill 会被误伤。
- 判定"是否为中性灰"不能用通道极差：slate 系 #94a3b8 极差 36 却是灰阶，#f0f9ff 极差 15 却是信息色浅底 → 改用人工白名单。
- **踩坑**：fallback 保护正则若写成 `var\(--x,\s*#`，因为 pre 截取不含 `#` 会失效，必须用 `$` 锚定（`var\(--x,\s*$`）。第一批的 12 处嵌套污染就是这个原因。
- 分档规则：color 按明度→text/-2/-3（L≥250 白字不动）；border→border/light/dark；background→surface/hover/active。
- 新增工具：`_design_ref/scan_gray.py`（统计）、`fix_gray.py`（CSS+内联 style，支持 --diff 预览）、`fix_gray_js.py`（echarts）。
- 验证：build 通过、smoke 15/15、三主题截图 60-63/70-73/80-83 均跟随。

## 服务入口与启动方式（常备）
- **后端**：NSSM 服务 `LexFlowBackend`，监听 **8001**（main.py `__main__` 段写死，非 .env）。重启唯一通路 = PowerShell `Start-Process -FilePath 'E:\FALV\tools\nssm\nssm.exe' -ArgumentList 'restart','LexFlowBackend' -Verb RunAs -Wait`。health：`http://localhost:8001/health` → `{"status":"ok","service":"LexFlow API"}`；openapi 共 619 paths。
- **生产前端**：后端 main.py 静态托管 `frontend/dist-prod`，入口 **http://localhost:8001** —— 改完 dist-prod 无需重启服务（读盘实时生效），但要重新 `npm run build` + 把 dist 整目录拷到 dist-prod。
- **开发前端**：`cd frontend && npm run dev` → **http://localhost:5173**，vite proxy `/api` → 8001。注意 vite 只监听 `[::1]`，`curl 127.0.0.1:5173` 会失败（000），必须用 `localhost` 或 `[::1]`。
- 登录：admin / lexflow2026。
- 排障提醒：本机有系统代理，curl 一律加 `--noproxy "*"`。
