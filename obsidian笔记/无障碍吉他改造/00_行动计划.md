## 🎸 伴奏能力规划 L1/L2/L3（2026-09-29 追加）

**前提修正**：距比赛还有**几十天**（不是几天）→ L1/L2/L3 全部在射程内，"黑客松阶段最多 L1"的旧口径作废。

**核心边界（不可越）**：主旋律归她。
- ❌ 机器替她奏出主旋律/和声并进主混音 = 等于放唱片，直接出局
- ✅ 给她一个伴奏环境（鼓 + 低音铺底），她弹主音

| 级别 | 形态 | 实现 | 评估 |
|---|---|---|---|
| **L1** | 播放伴奏轨 | 蓝牙音箱 / DFPlayer Mini 放 loop | 一天可加；灰色地带，必须守红线 |
| **L2** | MIDI 接入宿主 | ESP32 BLE-MIDI → iPad / 电脑音源 | **推荐**；电吉他手的标准玩法；顺带掩盖机械噪声 |
| **L3** | 实时自动配器 | 装置读她弹的每个音 → 实时补低音 + 和声 | 最强，哲学最干净（伴随音也由她触发）；工程量最大 |

**红线三条**：① 伴奏轨不含主旋律 ② 伴奏音量必须低于她 ③ 静音开关在她手边

**工程铁律**：**别让 ESP32 兼做音响**——音频解码会抢实时控制的时间片。音频一路、控制一路，物理分开。

## 📅 倒排（几十天口径）

**真正的约束不是时间，是三条验证链：**

1. **力够不够** —— go/no-go，要等件，不可压缩
2. **机械迭代周期** —— 打印 → 装配 → 上琴试 → 改图 → 再打印，一轮 2~3 天，通常 3~4 轮
3. **她的时间** —— 真瓶颈，她是测试者，不是随时可约

| 段 | 触发条件 | 干什么 |
|---|---|---|
| **0 · 立刻** | 不等件 | BLE-MIDI 固件 / L3 和声规则表 / 3D 图纸（卡箍·滑座·压弦指支架）/ 软性件采购 |
| **1 · 件到** | 物流到货 | 单通道台架：力 / 行程 / 温升 / 回零精度 → 定执行器方案 |
| **2 · 机械成型** | 台架通过 | 整机装配 → 换 009 弦 → 逐弦标定 → **第一次真人测试** |
| **3 · 功能升级** | 整机跑通 | v3 换把联调 → L2 落地 → L3（有余量则上） |
| **4 · 收尾** | 赛前 | 排练 / 备份件 / 答辩材料 |

**备份件原则**：几十天最大的价值不是多堆功能，是**有余量做备份**——桥板、压弦指各做 2 份，现场翻车 5 分钟换掉。

## 🎛️ L2 触发方式升级（2026-09-29 追加）

**问题**：L2 第一版"点触摸就出声"，NoteOn 跟右手拨弦脱钩了——哲学上不干净。

**解法**：**触摸 = 选弦（武装），拨弦瞬态 = 触发发声。**
- "她没拨弦，一个音都不响"从固件里的一句判断，**升级为麦克风层面的事实**
- 力度（velocity）由拨弦强度决定 → **强弱真的归她**
- 同时按住多块铜箔 = 扫出一个和弦

**必带的安全闸门**：**没有触摸武装 → 麦克风听到也不发任何音。** 装置贴着琴、功放就在旁边，麦克风必然听到喇叭声，没有这道闸门会自激。串口会打印"检测到拨弦，但没有弦被选中 → 不发任何音（防自激）"——**这一行就是答辩证据**。

固件：`E:\音乐\档3实现\l2_midi_s3_mic\l2_midi_s3_mic.ino` · 施工手册见 [[03_L2施工与操作手册]]

**屏幕口径锁定**：只做输出（音名/把位/弦状态），**交互永远留在物理铜箔**。虚拟指板点选否决——她手张不开，格子比琴弦还密，**否决理由与屏幕大小无关**。屏幕排最低优先级，可以完全不接（现场要观众看清就串口投屏）。

## 🎯 2026-09-29 目标锁定：真弹（本轮最高口径，覆盖以上所有旧口径）

- **Z 拍板：真弹是硬要求。** 原话——"不然怎么能体现自己的价值？这样的话，别人买一个无弦吉他就可以了。这才是重点。"
- **定义**：弦必须被压到品丝上，音由**这把琴**发出。没有东西压弦 = 永远不是真弹，这是物理不是偏好。
- **关系**：右手归她、机器当她的左手 = **合作**，不是替代。
- **连带结论**：纯电子 L2 **不能作为终点**（← 修正 [[00_行动计划]] 上文"L2 推荐"的定位；L2 降为**机械手的驱动层 + 现场保底**）。
- **竞品判据（答辩一页讲完）**：LiberLive C1 无弦吉他 ¥1788~2099 / $359~449，采样合成发声 + 内置鼓机贝斯，主打的正是电子发声。→ 我们若走电子，就是"一台更差的无弦吉他"。
- **我们只剩三条护城河**：①真弦振动发声 ②她真的在演奏一把实在的乐器 ③真琴的指板与换把。
- **采购口径（2026-09-29 二次修正）**：**零采购不是本项目的条件，从决策轴里划掉——钱不是约束。** 真弹必然需要执行器，选型只由「能不能做到 + 余量够不够」决定，**不按价格**。分步只为避免一次买错 6 个执行器，**样件单与批量单同时下**，物流不浪费第二轮。

- **下一步只有两件**：① 换 009 弦 → 厨房秤测神器 9 键按键力（今天就能做）② 下电磁铁样件单（**三种型号一起**：5N / 25N / 大行程）→ 台架压秤出「力—体积」曲线，当天定型号。两组数字回来，M1/M2 当场定。
