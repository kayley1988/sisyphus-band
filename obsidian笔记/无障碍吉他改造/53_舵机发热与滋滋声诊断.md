# 53_舵机发热与滋滋声诊断

> 2026-10-10 · 归属：[[50_原项目舵机安装口径]] / [[51_压弦12路接线卡]]
> 现象：Z 反馈"舵机弄完一次怎么这么热，还有点滋滋的声音"

---

## 一、结论先给

| 现象 | 判定 | 说明 |
|---|---|---|
| **温热**（手能一直摸，<55℃）| ✅ 正常 | 模拟舵机保持 PWM 时本来就发热 |
| **滋滋/吱吱（持续）** | ⚠️ 分两种 | 轻微 = 模拟舵机寻位抖动（正常）；**较响 = 有阻力顶着** |
| **烫得缩手**（>70℃）| ❌ 危险 | 立即断 5V —— 会烧绕组 |
| **热 + 响 + 不动** | ❌ 堵转 | 机械顶死，几分钟就报废 |

---

## 二、根因①（确定）：固件**故意**让舵机一直保持

`esp32_platformio/src/playback_engine.cpp:314`

```cpp
// servo::disable_all() 已移除——舵机保持最后一次 PWM 输出，有保持力矩不会乱动
```

意思是：**一首曲子弹完，12 个压弦舵机继续通电、继续输出 PWM**，维持在最后那个压弦姿态上。

- **为什么这么做**：琴弦有张力，一旦断 PWM 舵机就失去力矩，会被弦顶回去、姿态乱掉。所以演奏结束**刻意不释放**。
- **代价**：持续通电 → 持续发热。**这是设计取舍，不是故障。**

> 对照：`servo_driver.cpp` 里其实有完整的失能能力（`disable_all()` / `disable_all_fast()`：
> 归位→校验→分组断电→拉 OE→PCA 进 SLEEP）。只有**显式操作**才走这条路：
> · ESC 中断演奏（`esp32_player` 的紧急停止 → 归位 + 失能）
> · `disable_all()` 二进制帧
> · 上电初始化后 PCA 默认 SLEEP（无 PWM 输出，舵机真失能）

## 三、根因②（可能）：机械阻力 → 堵转发热

同样是"保持"，**无负载的 90° 中位电流约 100~200mA**（只温），
**顶死位置的堵转电流能到 1.5~2.5A**（几分钟烫手）——差 **10 倍以上**。

按概率排：

1. **套齿轮齿条时没在 90° 中位**（最高概率）→ 每个角度都在"顶着"跑
2. **齿条长度选错**（低=齿条1 / 高=齿条3）→ 压弦头顶到琴颈或够不到
3. **螺丝锁太死** → 齿轮箱阻力大，每次动作都在硬扛
4. 长时间连续测试（走马灯 / 整曲演奏 222s）→ 累积

## 四、滋滋声是怎么回事

**模拟舵机（MG996R 等）的固有特性**：

- 它靠内部电位器 + 比较电路"寻位"，**到达目标角度后仍在不停微调** → 线圈有 50Hz 工频声 + 齿隙共振 → "滋滋"
- **数字舵机**（DS3218 等）死区窄、寻位干净 → 明显更安静
- PCA9685 输出 50Hz（PRESCALE=121，✅ 正确值）→ 不是频率错导致的嗡声

⇒ **轻微滋滋 = 正常，不用管**；**明显较响 = 有阻力**（对应根因②）。

## 五、一个 30 秒判别法

**拔掉舵机的橙线（信号），只留红(+5V) + 棕(GND)：**

| 结果 | 说明 | 处理 |
|---|---|---|
| **安静了、慢慢凉** | PWM 保持 / 机械阻力 | 见下"处理" |
| **还是响、还是热** | 舵机内部故障或供电异常 | 换舵机 / 查电源 |

## 六、处理

### A. 让它凉下来

**① 软件急停（不拆线，2026-10-10 实测有效 ✅）**

脚本 `E:\音乐\档3实现\servo_off.py`（插上小智板 USB 后跑）：

```bash
cd "E:/音乐/档3实现"
E:/音乐/拨云_开源参考/liguanxi_Automatic_guitar/.venv/Scripts/python.exe servo_off.py
# 自动找 CH340 口；也可 --port COM4 ；--dry 只看不发
```

它实际发的是 ASCII 命令 **`CONFIG_APPLY`**（`commander/cmd_nvs.cpp`）：

```
chord::reset_position()  →  delay(300ms)  →  servo::clear_disable_batch_cache()  →  servo::disable_all()
```

`disable_all()` 六步（`servo_driver.cpp:551`）：归位 → 校验 10 路 → 分组断电 → **拉 OE + PCA MODE1=0x31(SLEEP) + LEDC 两路清零** ⇒ 16 路 PCA + 2 路直驱**全部失去 PWM**。

实测回显：`CONFIG_LOAD → OK loaded` → `CONFIG_APPLY → >OK`（**要等约 5 秒**，内部有多个 1s 延时）→
`STATUS 31 13 21 13 0 1 0 0`，第 5 位 = `servo::is_enabled()` = **0 已失能**；ADC 电流字段 `101 93 101 146 → 31 13 21 13` 同步下降。

> `STATUS` 8 字段（`cmd_legacy.cpp:114`）：`和弦电流 / 拨弦电流 / 电池电压 / 温度NTC`（ADC 原始 0~4095）+ `servo_enabled / calib_valid / playing / progress`。

**② 物理断 5V（最硬）** —— 拔舵机电源（或 PCA 的 V+ 端子线）。
⚠️ 只"停服务"或"停演奏"**不会**断电（根因①）。**PS：任何后续舵机动作（PLAY / PCA / PWM / 校准）都会 `enable_all()` 重新上电。**

### A.1 局部发烫（不是全部）→ 是"某一路装歪/插错"

2026-10-10 实测：**只有 11 号、12 号两个舵机非常烫**，其余只是温。这**排除**了"全局保持发热"（那会让所有舵机均匀温）——

| 可能 | 判据 | 处理 |
|---|---|---|
| **插错格**（插到拨弦区） | 前 6 格（靠绿端子）= **拨弦专用**；压弦必须 7~16 格。插错会被按"拨弦角度"驱动 → 大幅顶死 | 见 [[51_压弦12路接线卡]] ② 表重插 |
| **机械顶死** | 手动推压弦头，推不动 / 有硬阻 | 回中 90° 重装齿轮齿条 |
| **本弦张力最大** | 11/12 = **弦6**（最粗的弦），压弦所需力矩最大 | 属正常偏热，但"非常烫"仍是顶死 |

**11 / 12 号是谁**（见 [[51_压弦12路接线卡]]）：

| 舵机 | 弦 | 角色 | 齿条 | 应插 |
|---|---|---|---|---|
| **11** | 6 弦 | 品12组（品1/2） | 齿条1 | PCA **第 10 格**（ch10）|
| **12** | 6 弦 | 品34组（品3/4） | 齿条3 | PCA **第 8 格**（ch8）|

⚠️ 注意：按表它们**不在靠绿端子的那几格**（从绿端子数起，第 8 / 10 格）。若你的插头实际在**靠绿端子的前几格**，就是插进了拨弦区 → 这就是它们最烫的原因。

### A.2 为什么"只有这两路在使劲"—— 因果链

**发热的公式只有一条：`烫 ← 电流大 ← 电机在使劲 ← 到不了目标位置`**

| 状态 | 电流 | 温度 |
|---|---|---|
| 到位后保持 | 0.1 ~ 0.2 A | 温热（<55℃，能一直摸）|
| **顶着到不了位** | **1.5 ~ 2.5 A** | **分钟级烫手（>70℃）** |

差 **10 倍以上**。所以"烫"本身就是"顶死"的探测器。

**为什么偏偏 11/12 到不了位 —— 三个候选，按概率排：**

| # | 候选 | 为什么会烫 | 判据 |
|---|---|---|---|
| ① | **插错格**（落进拨弦区 1~6）| 固件给这格发的是**拨弦角度**，而挂的是压弦齿条 → 齿条被推到死点 | 报出信号线实际格号，≠ ch10/ch8 即中 |
| ② | **齿条顶死**（长度错 / 未回中装齿轮）| 每个动作都在撞限位，全程堵转 | 手动推压弦头，**推不动 / 有硬阻** |
| ③ | 弦 6 张力最大 | 只是"更费力"，**不足以解释"非常烫"** | 若 ①② 都排除才考虑 |

> 补充：走马灯 / 演奏最后**停在 120° 而非 90°** 时，也可能正好停在压弦死点上 → 表现为"跑完一次就烫"。

### A.3 三步定位法（10 分钟）

| 步 | 做法 | 结论 |
|---|---|---|
| **1 · 30 秒** | **拔掉 11/12 的橙线**，只留红 + 棕通电 | 凉了 → 是信号/角度问题，走第 2 步；**还烫** → 舵机本体坏或供电异常 → 换舵机 |
| **2 · 2 分钟** | 报出 11/12 的**橙色信号线各自插在第几格**（从绿端子那端数）| 必须是 **ch10 / ch8**。若在 1~6 格 = 拨弦区 → 重插 |
| **3 · 5 分钟** | 断电，**用手推这两路的压弦头** | 能轻松推 ±3mm → 机械 OK，问题在信号；**推不动** → 齿条顶死 → 拆下重做"回中 90° 套齿轮齿条" |
| 备用 | 用**舵机测试仪**单独测 11/12（脱离整机）| 测试仪下不烫 → 确认是系统侧问题；照样烫 → 舵机本体换掉 |

### B. 如果是装的问题

**回中 90° 重装齿轮齿条**（SOP 见 [[50_原项目舵机安装口径]]）：
1. 舵机测试仪 → 旋钮转中间 → 停住（= 90° 中位）
2. **保持通电**，在中位套齿轮、插齿条
3. 螺丝**对角分次**拧，不要一次锁死
4. 装好后用手推压弦头，应能轻松推动 ±3mm，**不顶死**

### C. 使用习惯

- 调试时**别让它长时间保持压弦位**（那个姿态电流最大）
- 测完立刻断 5V
- 整曲演奏（3~4 分钟）会明显升温 —— **跑一两遍就让它歇**
