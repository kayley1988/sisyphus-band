## 🔌 接线定稿

> 纪律：给脚号必须从板定义交叉验证；先接信号地、后上动力电（同 [[32_PCA9685与小智板接线]]）。

### 通道 1：压弦组（必接）

| MAX471 模块脚 | 接到 | 说明 |
|---|---|---|
| **+ / −**（电流 path） | **串**在 5V20A 电源 → PCA9685 V+ 的动力主路上 | 所有 12 路压弦舵机的电流都从这里走，测总电流即压弦组电流 |
| **AT**（模拟输出） | **1kΩ 电阻 → 小智 GPIO4** | 1V/A 标度；1kΩ 是 datasheet 建议的输出串联保护 |
| VCC | 小智板 3.3V | 模块逻辑供电 |
| GND | 与小智板/PCA9685 **共地** | 全系统一条地，不共地读数全废 |

### 通道 2：拨弦组（可后补）

| MAX471 模块脚 | 接到 | 说明 |
|---|---|---|
| + / − | 串在另一路 5V → 拨弦 6 舵机动力线 | 拨弦组独立测量 |
| AT | 1kΩ → **GPIO5** | 同上 |
| VCC/GND | 3.3V / 共地 | 同上 |

**手头只有一块模块时**：先接通道 1（压弦组是 her 模式主角），**AIN1(GPIO5) 用杜邦线接地**，拨弦组读数归零不影响验收。

### ⚠️ 三个坑（验收前必读）

1. **±3A 量程削顶**：多舵机同动实测峰值 ~3.1A，MAX471 满量程 3A 会削顶——固件 5A 过流阈值形同虚设。本阶段只用于**到位检测/热保护/标定**（都只看小电流变化），满载过流联调二期换大量程方案再议
2. **AT 脚悬空 = 读数满偏**：1kΩ 电阻务必串在 AT→GPIO4 之间，模块 VCC 没供上电时 GPIO4 读数会漂到满量程
3. **串联方向**：MAX471 有方向性（+进 −出），接反读数为负——不影响绝对值判读，但标定时统一方向

## ✅ 验收 SOP（四步）

### Step 0 · 准备

```bash
# 泰山派上（adb 或板载终端）
systemctl stop guitar          # guitar.service 独占 UART3，必须先停
# 推送验收脚本
adb push tools/max471_check.py /data/local/tmp/
```

脚本已落盘：`E:\音乐\拨云_开源参考\liguanxi_Automatic_guitar\tools\max471_check.py`（零依赖，只要 pyserial）。

### Step 1 · 静态验收（不接舵机动力，只验证链路+空载基线）

```bash
cd /data/local/tmp && python3 max471_check.py --seconds 30
```

**PASS 判据**（脚本自动判定）：
- ✓ 帧率 ≥ 15 帧/秒（理论 ~20）
- ✓ CRC 错误率 < 1%
- ✓ 压弦组空载基线 < 0.10A

### Step 2 · 带载验收（MAX471 串入动力主路后）

手动触发 1 个压弦舵机（full 模式单曲 或 上位机单点动），脚本实时行应看到压弦组电流**明显跳变**（单舵机 ~0.3~0.8A 量级），松开回落。

### Step 3 · 数据留存

```bash
python3 max471_check.py --seconds 60 > max471_accept.log 2>&1
```

日志拉回本地归档到 `logs/system/`，验收结论写回本笔记。

### Step 4 · 解除现场

```bash
systemctl start guitar         # 或 scripts/board_dev.sh start
```
