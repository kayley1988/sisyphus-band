> **一句话定位**：给《拨云》补上第三层托管点 —— **服务器只做「随时可开的档案室」，重活（分轨/改谱/渲染）全留在电脑本地，算完定时上传**。板子永远只负责演奏，不依赖服务器。

- **日期**：2026-10-09
- **状态**：🟢 **已部署上线**（阿里云 ECS，`guitar-site` 服务常驻 + 开机自启）；外网访问待 Z 在**安全组放行 8090**
- **代码**：`tools/push_to_server.py`、`deploy/server_site.py`、`deploy/server_bootstrap.sh`、`deploy/server_sync.example.json`

## 1. 为什么需要这一层

Z 的原话：「**服务器里放个我随时可以用的**，然后那些**分轨呀、改呀之类的在本地跑**，然后**定时上传**。」

翻译成架构语言：这是标准的 **「薄服务器 + 本地工坊」**。

- 板子（泰山派）要开机、要插数据线 → 不能当「随时随地可看」的托管点；
- 电脑算力强、还能跑 DeepSeek 纠错 / 分轨 → 重活天然属于它，但它不常开；
- **服务器 7×24 在线、手机在外面也能连** → 正好补这个缺口。

已有的 `archive_performance.py` 只打通了「板子 → 电脑」；这一层就是补上「电脑 → 服务器」。

## 2. 三段式职责（固定方案）

```mermaid
flowchart LR
    A["泰山派 · 板子<br/>演奏现场<br/><i>离线自足</i>"]
    B["电脑 · 工坊<br/>分轨 · 改谱 · 渲染<br/><i>算完就传</i>"]
    C["服务器 · 档案室<br/>随时可开 · 7×24<br/><i>不开机也能看</i>"]
    A -- "adb pull" --> B
    B -- "rsync / scp" --> C
```

| 层 | 角色 | 负责 | 绝不做 |
|---|---|---|---|
| 泰山派板子 | 演奏本体 | 压弦、触发、OLED、现场实时看板、录她的演奏 | 不联网、不依赖服务器、不上镜像 |
| 电脑 | 工坊（要算力） | 爬谱、AI 纠错、分轨、和弦归约、渲染长期看板 | 不做现场实时（要开机，不适合） |
| 服务器 | 档案室（要常驻） | **只读展示**：看板 + 曲库下载 | 不发指令、不连板子、不写数据 |

> 🔑 **铁律**：演奏本体只在板子本地闭环 —— **服务器掉线，她照样弹**。服务器是「镜像的展示窗」，不是链路里的一环。

## 4. 用法（三步）

**① 电脑：配一次**
```bash
cp deploy/server_sync.example.json deploy/server_sync.json
# 填 host / user / identity，然后把本机公钥加到服务器 ~/.ssh/authorized_keys
```

**② 电脑：每次收工后推**（可挂 Windows 计划任务）
```bash
python tools/archive_performance.py sync     # 板子 → 电脑（板子开机时做）
python tools/push_to_server.py --render       # 顺手刷新看板并推到服务器
```

**③ 服务器：装一次（一次性）**
```bash
# 在服务器上，进到仓库 deploy/ 目录
sudo bash server_bootstrap.sh --port 8080
# 之后访问  http://<服务器IP>:8080/
```

想看会传什么、又不想动服务器：`python tools/push_to_server.py --dry-run`。

## 6. 诚实说明已知边界

- **已上真机**：`server_site.py` 已在阿里云 ECS 上真实运行并验证（healthz / 401 / 曲库列表）；推送器已真实推送成功。
- **bootstrap 跨发行版**：自动识别 `apt / dnf / yum`，阿里云 Linux（dnf）与 Ubuntu（apt）都能跑；已加「优先探测预装 python3.11、不装系统包」。
- **传输假设 SSH 可达**：本机需有 `ssh`/`scp`（Windows 自带 OpenSSH 即可）；有 `rsync` 则优先用（能做镜像删除），没有则退回 `scp`（只覆盖同名，不删）。
- **本机没有 rsync** → 当前走 `scp`，因此 `archive/` 属于**只增改不删**（旧档案不会被镜像删除）。
- **曲库已做筛选**：只推 `输出结果*.csv`，不推 39M 的中间图片；服务器站点默认**不监听 0.0.0.0 之外的额外暴露**，但当前已绑定 `0.0.0.0:8090` 且**带口令**——公网放行前请确认口令强度。
- 曲库推的是《拨云》识别产出的谱子内容，若其中含隐私信息请注意。
