## 🎯 为什么做这件事

her 模式现在是**当下瞬间的配合**——她碰、机器压，过去就没了。而"她的演奏"是整个项目最核心的资产：答辩要证明"她真的在演奏"，靠嘴说不如**拿数据说**。

一句话：**从"机器能做什么"转到"机器能记住她什么"。** 全零采购，纯代码。

## 📐 为什么单独目录、不复用系统日志（重要）

`logs/system/*.jsonl` 有**保留策略**（10MiB/7 天/256MiB 轮转删除，`log_retention.py`）——那是排障日志，可以被清。而她的演奏档案是**长期资产**（康复跟踪 / 答辩证据 / 成长曲线），绝不能跟着系统日志被轮转掉。

→ 落 **`logs/performance/session_YYYYMMDD-HHMMSS[_tag].jsonl`**，不在保留策略管辖内。

## 📋 Schema v1（一行一事件，末尾 summary）

**头行**
```json
{"kind":"session_start","schema":1,"session_id":"20261009-115135-练习-第3天",
 "started_at":"2026-10-09T11:51:35.707+08:00","mono":12345.6,"tag":"练习-第3天",
 "config":{"perf_mode":"her","trigger_mode":"touch","actions":["chord"],
           "chord_map":{"0":"C","1":"G"},"hold_timeout_s":45.0,"debounce_samples":3},
 "device":{}}
```

**事件行**（`t` = 相对开场的秒数，3 位小数）

| kind | 关键字段 | 含义 |
|---|---|---|
| `chord_press` | chord, src(touch/ui/timer), seq | **她的动作主记录点**（换和弦） |
| `chord_release` | chord, held_s, reason | reason ∈ manual / superseded（没松手就换）/ guard_timeout / session_end |
| `strum` | strings | 拨弦（her 模式下一般无） |
| `position` | position | 换把（二期 v3） |
| `mode_change` | from, to | full/her 运行时切换 |
| `guard_warn` | chord, held_s | 守护层预警（保持过久） |
| `guard_timeout` | chord, held_s | 守护层超时自动松弦（= 她卡住了/忘了松） |

**末行 summary**
```json
{"kind":"session_end","summary":{
 "duration_s":69.3,"chord_changes":7,"distinct_chords":5,"strum_count":0,
 "holds":7,"holds_normal":6,"avg_hold_s":8.7,"max_hold_s":46.0,
 "timeouts":1,"warns":1,"change_gap_avg_s":3.7,"change_gap_max_s":4.8,
 "by_chord":{"Em":{"n":1,"avg":46.0,"max":46.0,"timeouts":1}, "...":{}}}}
```

**这张 summary 本身就是她的画像**：`by_chord` 里哪个和弦磨得久 = 哪个手势难；`change_gap` = 换和弦速度；`timeouts` = 她卡住的次数。

## 🛡️ 三条纪律（写进代码）

1. **记录失败绝不打断演奏**：所有 `on_*` 全程 try/except，异常吞掉 + 只警告一次（已单测：非法目录下不抛）
2. **只记"已发生的事"**：记录器不产生任何触发 → 不碰硬规则①（触发权在人）
3. **逐行 flush**：事件率极低（人手换和弦），掉电最多丢最后一行

## ▶️ 怎么用

```bash
# 1) 打开记录（config.yaml，板上同样改）
trigger:
  record:
    enabled: true
    dir: logs/performance
    tag: "练习-第1天"     # 可选，拼进文件名

# 2) 她弹一段 → 收场时自动落档
# 3) 看档案
python3 tools/her_session_report.py --last
python3 tools/her_session_report.py --last --replay-speed 4   # 回放时序预览
```
