# 32 · PCA9685 与小智板接线方案（2026-10-05 定稿）

> 一句话：小智板用 GPIO1/2 作 I2C 驱动 PCA9685（addr 0x40），OE 接 GPIO47，**另有 2 路压弦舵机不走 PCA、直接由 GPIO40/GPIO39 的 LEDC 驱动**；PCA 逻辑侧取 3.3V，舵机动力单独走 **5V/20A 直流开关电源**（由 220V 市电转换而来，**它不是市电本身**），四方共地。
>
> 状态：✅ 依据固件定稿，⚠️ 未实机验证 ｜ 固件来源：`esp32_platformio/src/config/board_profiles.cpp` 的 `XIAOZHI_PROFILE`

---

## 🔴 最关键的一条：18 路舵机不是全走 PCA9685

之前一直说"18 路 → PCA9685"，**不准确**。实际分配：

| 类别 | 数量 | 走哪里 |
|---|---|---|
| 压弦舵机 | 12 | **10 路 → PCA9685**，**2 路 → ESP32 GPIO 直驱** |
| 拨弦舵机 | 6 | 全部 → PCA9685 |
| **PCA 占用** | 16 | 正好 1~16 全用满 |

> ❓ **"能不能 18 路全插 PCA9685？"→ 不能，物理上就做不到。** PCA9685 芯片只有 **16 个 PWM 通道**，18 > 16 装不下；固件也已把这 16 个通道排满（`board_profiles.cpp:68` 校验断言 C16：*all 16 PCA channels used exactly once*）。剩下 2 路（**第 1 弦 ch0、第 4 弦 ch0**）必修走 ESP32 的 LEDC → **GPIO40 / GPIO39**；且它们**不由 PCA 供电**，红/棕线要单独并到 5V 母线与 GND。

固件依据（`board_profiles.cpp` XIAOZHI_PROFILE）：

```c
.chord_ch = { PIN_NONE, 15, 13, 11, 9, 7, PIN_NONE, 16, 14, 12, 10, 8 },
.strum_ch = { 2, 4, 6, 1, 3, 5 },
.pwm_slot = { 0, 1 },
.pin.pwm  = { 40, 39 },      /* LEDC 直驱舵机 */
```

`chord_ch` 里两个 `PIN_NONE`（索引 0 和 6）在 `buildMaps()` 中被解析为 LEDC 直驱：
- 索引 0 → `pwm_slot[0]` → `pin.pwm[0]` = **GPIO40**
- 索引 6 → `pwm_slot[1]` → `pin.pwm[1]` = **GPIO39**

## 🔌 一、控制接线（小智板 ↔ PCA9685）

| PCA9685 引脚 | 接小智板 | 说明 |
|---|---|---|
| **SCL** | **GPIO1**（丝印 G1） | 固件 `PIN_I2C_SCL = 1`，各版恒定 |
| **SDA** | **GPIO2**（丝印 G2） | 固件 `PIN_I2C_SDA = 2` |
| **OE** | **GPIO47** | 低有效；固件 `setPcaOutputsEnabled()` 会驱动它 |
| **VCC**（逻辑） | 小智板 **3V3** | ⚠️ 不是 5V，见下方致命点① |
| **GND** | 小智板 **GND** | 必须共地 |

小智板上 UART 的 G41/G42 已接泰山派 8/10 脚，保持不动。

## ⚡ 二、动力接线（舵机电源）

### 这个"5V 20A"到底是什么（术语澄清）

- **市电 = 墙上插座的 220V 交流电（AC）**，绝不能直接接舵机，接上去就是炸。
- **5V 20A** 指的是一台 **AC-DC 开关电源**：输入 220V AC，输出 **5V 直流（DC）**，**最大可供 20A**（即 100W）。它插市电，但输出的是 5V 直流。
- 所以完整说法应是：**"220V 市电 → 5V/20A 开关电源 → PCA9685 的 V+ 与 18 路舵机"**。表里简写"市电"是指这条链路的源头，不是让你把市电接上去。

### 接线

| 点 | 接法 |
|---|---|
| PCA9685 **V+** | 5V/20A 直流电源 **+**（螺丝端子 / DC 插头正极） |
| PCA9685 **GND** | 直流电源 **−**，并与小智板 GND 汇合 |
| 18 个舵机的红/棕线 | 全部并到这条 5V 母线（**⚠️ 不许走面包板**） |

### 为什么是 20A

| 项 | 数值 |
|---|---|
| 12 个压弦 MG996R 堵转 | 单颗约 1.5~2.5A，理论峰值很大 |
| 6 个拨弦 MG90S | 单颗约 0.5~1A |
| 实测/估算峰值 | **≈3.12A** |

S-100-5 给 20A ≈ **6 倍余量**。余量不是浪费：舵机启动瞬间是冲击电流，电源一旦被拉到欠压，ESP32 会复位、舵机会抽搐。按 Z 的口径"钱不是约束"，这台电源几乎是最不该省的一项。

### 可选型号

| 型号 | 形态 | 备注 |
|---|---|---|
| 明纬 **RS-100-5** | 带壳、螺丝端子 | 最稳，5V/18A（≈90W），工业级 |
| 明纬 **LRS-100-5** | 裸板/带壳 | 5V/18A，常见好买 |
| 杂牌 **5V 20A 100W** 开关电源 | 带壳螺丝端子 | 便宜够用，注意看是否有过流保护与 3C |

买回来第一件事：**万用表量输出电压确实是 5.0~5.2V 再接线**。

### ✅ 三步上电（不要一次全接）

1. **只接信号，不接舵机**：SCL/SDA/OE/VCC(3.3V)/GND → I2C 扫到 **0x40** 才算通。此时不需要铁盒电源。
2. **单点动验通道**：只接 1 个舵机，逐通道点动，确认丝印 **0~15 还是 1~16**（固件 `setPWM(ch-1)`）。
3. **上动力**：断 V+=VCC 跳线 → 铁盒 +V/−V 接 PCA 的 V+ 与汇流排 → 先接信号地再上 5V → 逐步加舵机。

### ❓ 接线前必须先确认的 4 件事

| # | 确认项 | 状态（2026-10-06 实照核对） |
|---|---|---|
| 1 | OE 是否引出 | ✅ **已引出**：模块顶/底各一排 6 针 `V+ VCC SDA SCL OE GND`，OE → 小智板 **G47** |
| 2 | 通道号怎么认 | ✅ **本板丝印不印数字**（2026-10-06 实照确认）。改用位置锚点：**离 V+ 绿端子第 N 格 = 固件 chN**（二分点动实测：最近格=ch1、最远格=ch16） |
| 3 | V+=VCC 是否分离 | ✅ **实测分离（2026-10-06，万用表蜂鸣档量 VCC 针 ↔ V+ 针，OL 不响）** —— 此版本天生分离，**致命点① 直接免掉**，无需找跳线帽 |
| 4 | 舵机插头线序（信号/红/棕） | 插时对色：橙(信号)→黄针、红→红针、棕→黑针；先用 1 个通道验证方向 |
| 5 | 180° 位置型（非 360° 连续旋转） | ⏳ 查购买页规格；通电中位脉宽：180° 停住保持，360° 转不停。**买到 360° 版 → 压弦/拨弦全废** |

**小智板实照定位（GOOUUU ESP32-S3-CAM，模组 N16R8，双 USB-C：OTG/TTL）**：右列丝印从上到下 `TX0 RX0 G1 G2 G42 G41 G40 G39 G38 … G47 G21 G20 G19 GND` —— **G40 / G39 都已引出**（直驱两路无忧）；G1/G2（I2C）、G47（OE）、G41/G42（UART，已接泰山派 8/10）全对上固件定义；左列含 G4/G5/G6/G9/G8（AIN 备用）与 3V3、5V、GND。

- **分阶段供电**：只验 1~2 路通道映射时，用充电宝/USB 5V 2A 就够（单颗 MG996R 空载 ~0.5A），不必上大电源。

## 📋 三、18 路通道对照表（★ 照这张插）

### 压弦舵机 12 个（每弦 2 个：ch0 / ch1）

弦序依据 `chord_engine.cpp compute_angles()`：`k[6] = {0,2,4,6,8,10}`，第 x 弦占 `idx k[x]` 与 `k[x]+1`。

| 弦 | ch0（品12组） | ch1（品34组） |
|---|---|---|
| **第 1 弦** | **GPIO40 直驱** | PCA 15 |
| 第 2 弦 | PCA 13 | PCA 11 |
| 第 3 弦 | PCA 9 | PCA 7 |
| **第 4 弦** | **GPIO39 直驱** | PCA 16 |
| 第 5 弦 | PCA 14 | PCA 12 |
| 第 6 弦 | PCA 10 | PCA 8 |

### 拨弦舵机 6 个

| 拨弦 index | PCA 通道 |
|---|---|
| 0 | 2 |
| 1 | 4 |
| 2 | 6 |
| 3 | 1 |
| 4 | 3 |
| 5 | 5 |

> 规律很好记：**PCA 1~6 = 拨弦，PCA 7~16 = 压弦**（仅适用于 XIAOZHI/V6.0 映射，V5.1 不同）。

### ✅ 通道号怎么认（本板实测定死：**看位置，不看丝印**）

固件 `setPWM(ch - 1, ...)`：软件通道是 **1..16**，传给库的是 **0..15**。

**本项目这块 V1246 蓝版：舵机排针旁不印数字**（丝印只有一个 `V+`，没印 0~15 或 1~16）。2026-10-06 用「单点动 + 二分定位」实测得到：

> ★ **从绿色 V+ 端子那一端起，数第 N 格（含） = 固件 ch N。**
> 实测：离 V+ **最近**的一格 = **ch1**；离 V+ **最远**的一格 = **ch16**。直线编号，无折返。

| 你的位置 | 固件通道 |
|---|---|
| 离 V+ 绿端子第 1 格（最近） | **ch1** |
| 离 V+ 第 2 格 | ch2 |
| … | … |
| 离 V+ 第 16 格（最远） | **ch16** |

**丝印不印数字不是问题——位置锚点比丝印更可靠。** 先认准 V+ 端子那一端，往远的数。

> ⚠️ 若你的板是**两排 8 格**或排针有折返，这两端结论仍不够；插满后必须做一次「逐路点名」（见第五节第 3 步）复核。
> 旧口径（"丝印标 0~15 就插 ch−1、标 1~16 就插 ch"）仅适用于印了数字的版本，本板不适用。

## ☠️ 四、五个致命点

| # | 风险 | 后果 | 做法 |
|---|---|---|---|
| ① | **PCA9685 上 V+ 与 VCC 的连通跳线未断开** | 5V 灌进 I2C 上拉 → **烧 ESP32 的 GPIO1/2** | 查板子上的跳线帽/焊点（常标 `V+=VCC`），**必须断开**；VCC 只接 3.3V。**（本项目这块 V1246 蓝版 2026-10-06 实测 VCC↔V+ OL 不响 = 天生分离，此条已豁免，但仍须保证 VCC 只接 3.3V）** |
| ② | **没共地** | I2C 通信失败、舵机抽搐 | 小智 GND = PCA GND = 电源 − = 舵机 GND，务必物理连通 |
| ③ | **OE 没接 GPIO47** | 固件拉高 OE = 禁能输出 → **舵机全不动** | 模块有 OE 针就接 GPIO47；没引出则 GPIO47 悬空（无害） |
| ④ | **舵机电源走面包板** | 面包板孔一般只扛 1A，3A 会**发热熔板** | 5V 动力线用 18AWG 硅胶线直连，端子拧紧 |
| ⑤ | **先上电后接线 / 带电插拔** | 打火、烧芯片 | 先接信号+地，最后上 5V；拆线先断 5V |

附带一条：GPIO40/39 直驱舵机输出的是 **3.3V PWM**，多数舵机能识别，但这两根线要**尽量短**，长线易受干扰。

### ✂️ 那 2 路直驱舵机怎么接（★ 物理接线，2026-10-06 补）

**一个针都不插 PCA**（16 格留给另外 16 个），3 根线分三处走：

| 舵机线 | 接到哪 | 怎么做 |
|---|---|---|
| **橙（信号）** | 小智板 **G40 / G39 排针** | 用一根**公-母杜邦线**：公针插进舵机 3P 插头的信号孔，母头套小智板排针。两只分别去 **G40 = 第 1 弦 ch0**、**G39 = 第 4 弦 ch0** |
| **红（电源）** | **5V 母线** | 与其余 16 个**同一根 5V**（从绿色端子 V+ 并联出来，或后续汇流排） |
| **棕（地）** | **GND 母线** | 同理，并进全系统共地 |

> ⚠️ 这 2 路**不经过 PCA 板**，PCA 不给它们供电——红/棕**必须自己并到电源母线**，别想从 PCA 排针那格取电（那格要留给 PCA 自己的通道）。

点动验证命令：

```
PWM 0 0      # GPIO40 → 第 1 弦 ch0
PWM 0 180
PWM 1 0      # GPIO39 → 第 4 弦 ch0
PWM 1 180
```

**台架顺序**：先把 16 路 PCA 插满、逐路点名通过 → **再单独接这 2 路**（变量隔离，出问题好定位）。

#### ✅ 实机接法（2026-10-06 验收通过）

| 线 | 落点 | 实测做法 |
|---|---|---|
| **橙（信号）** | 小智板 **G40 / G39** 排针 | 直接插（G40 = 第 1 弦 ch0、G39 = 第 4 弦 ch0） |
| **红（+5V）** | PCA 绿色端子 **右螺丝 V+** | 与电源红线**绞接**后共用一根"引线"进端子（见下） |
| **棕（GND）** | **小智板排针上的 GND 针**（就近）或 GND 母线 | ★★ **漏了这根 = 舵机绝对不动**，先查它 |

**🔑 绿色端子孔太小、塞不进 3 根线 → 用"引线分流"（Z 的方案，实测有效）**：

1. 取一根**杜邦线，两端都剥皮**
2. **一端**（单根细线）放进绿色端子螺丝孔 —— 孔里只走这一根，进得去
3. **另一端**与 2 根舵机红线（+ 电源红线）**在孔外绞接** —— 不受孔径限制

**必须遵守 3 条**：

- 绞接点**绞 6~8 圈**；有烙铁**必须上锡** —— 这是 5V 动力节点，要过 3.5~5.5A，虚接会发热甚至打火
- 绞接点**必须用热缩管 / 电工胶带包死** —— 红线裸露碰到地 = 直接短路
- ⚠️ **杜邦线 26AWG 安全载流只有 ~1A（顶天 2A）**：**台架空跑够用；上琴带力矩前必须换粗线**（或两根并一股）

> 另一条经验：绿色端子的螺丝孔是按**单根线**设计的，2~3 根硬塞会拧不实。就算勉强塞进去也建议按上面"引线分流"重做，接触可靠得多。**"孔小"不是换端子的理由，是分流的理由。**

### 第 2 步：接 1 个舵机 + 5V 动力 —— ✅ 2026-10-06 验收通过

1. **先量电源输出** 5.0~5.2V（万用表 DC 档）。第 2 步负载仅 1 个舵机（<1A），可用 **PD 充电头 + USB-A 取电线**（5V/4A 足够，USB-A 口固定 5V 无协议协商）；取电线的红/黑**先量极性再接线**（剪线取电的线色不一定准）
2. 电源正 → PCA **V+ 螺丝端子**；电源负 → PCA **GND**（与已有共地汇合）
   ★ **绿色 2 位螺丝端子极性（本模块实测定死）**：**左侧 = GND、右侧 = V+**。该端子**无清晰丝印**，通用判定法 = 蜂鸣档对排针上已确认的 **V+ 针 / GND 针**做**四点交叉验证**，四条全对才作数（可排除"笔尖互碰""端子金属框连通"造成的假响）：
   ```
   ① 左 ↔ GND针 = 响   ② 左 ↔ V+针 = 不响
   ③ 右 ↔ V+针  = 响   ④ 右 ↔ GND针 = 不响
   ```
   螺丝端子与顶部排针是**同一电源轨的两个出口**（V+ 轨 / GND 轨各一）。
3. 只插 **1 个舵机**（MG90S 更安全，电流小），插在**离 V+ 端子最近的一格**
4. 上电 → 发命令点动：

```

PCA 1 180
```

5. **实测结果**：舵机随命令转动 → 全链路 **PC → 小智板 → PCA9685 → 舵机** 打通 ✅；通道 = **固件 ch1**，位于**离 V+ 最近那一格**。随后把舵机挪到**离 V+ 最远那一格**，ch16 动作 → **两端确定，本板为直线编号**。

6. **定位手法（本板丝印无数字时通用，已存技能）**：全扫 `PCA 1..16` 各 0→180° → 折半 1~8 / 9~16 → 1~4 / 5~8 → 分组对比「ch K 连动 3 次 → 停 3 秒 → ch K+1 连动 3 次」，问用户"前面动还是后面动"，2~3 轮锁定。

> ⚠️ 上电状态**不要插拔舵机**（打火）。另外：**打开串口这个动作本身会触发板子复位**（DTR/RTS 置位），舵机回中抽一下是正常现象，不是故障。

## ⚡ 三级供电体系：为什么泰山派 / ESP32 / PCA9685 电压不一样

> 一句话：**不是"电压不一致"，是分层分工**——5V 是动力母线（出力气），3.3V 是逻辑母线（出信号）。所有数字器件的 IO 都只认 3.3V，5V 只喂舵机。

### 三层电压

| 层级 | 电压 | 谁在用 | 来源 |
|---|---|---|---|
| ① 动力母线 | **5V** | 18 路舵机、PCA9685 的 **V+**、两块板的 USB 输入 | 5V 适配器 |
| ② 逻辑母线 | **3.3V** | ESP32-S3 IO、RK3566 IO、PCA9685 的 **VCC**、OLED、TTP223×6、I2C 上拉 | 两块板各自的板载 PMIC / LDO 把 5V 降下来 |
| ③ 芯片内核 | **0.9~1.1V** | 芯片硅片内部 | 板载 DC-DC，**外部看不到、永远不用管** |

### 三条铁律

1. **PCA9685 的 VCC 必须取 3.3V，不能取 5V** —— SDA/SCL 的上拉电阻接在 VCC 上；VCC=5V 就会把 5V 灌进 ESP32 的 3.3V GPIO，烧口子。这也是 V+=VCC 跳线**必须断开**的原因。
2. **必须共地** —— 5V、3.3V 两域之间如果没有共同参考点，I2C/UART 的电平就解不出来，表现为"扫不到 0x40 / 串口乱码 / 舵机乱抽"。
3. **I2C / UART 能直连，恰恰因为两边同为 3.3V** —— 泰山派 IO 3.3V、ESP32-S3 IO 3.3V，天生兼容，不需要电平转换板（若换 5V 主控就必须加）。

### 常见误解

| 误解 | 实际 |
|---|---|
| "ESP32 是 5V 的" | ❌ 芯片只吃 **3.3V**；板上的 5V 是**输入**，经板载 LDO 降到 3.3V 才给芯片 |
| "泰山派要 12V" | ❌ 本板是 **USB-C 5V** 输入，板载 PMIC 再转出 3.3V / 1.8V / 1.1V |
| "PCA9685 也吃 5V" | ⚠️ 只有 **V+（舵机动力）** 是 5V；**VCC（逻辑）** 接 3.3V |
| "3.3V 是随便定的" | ❌ 行业事实标准：5V TTL → 3.3V（工艺缩小后 5V 会击穿栅氧），现代 MCU/SoC 的 IO 几乎全是 3.3V |

> 记忆点：**5V 管"转得动"，3.3V 管"听得懂"。** 要驱动负载 → 5V；要传信号 → 3.3V。PCA9685 一个器件跨两域，是全系统唯一同时接两种电压的芯片。
