## 一、官方原文（立创开源页，逐字摘）

> ### 🔧 硬件整体结构
> 整体结构分为 **3 段**，分别是**和弦、主控、拨弦**，使用**螺丝夹住胶块进行固定**。
>
> #### 🎼 和弦内部结构
> 按照 **6 弦 4 品设计共 24 个点**需要按压，**每个舵机正向反向各按压一个点，一共 12 个舵机**，通过**齿轮齿条传动**。
>
> #### 🎵 拨弦结构
> **6 个舵机，每个舵机对应 1 个弦**，具有**拨片调节结构，可以前后调节拨片，使用螺丝固定**。
>
> #### 🖥️ 主控板结构
> 电路 3 层结构，分别是最底下泰山派主控板、中间按钮+舵机驱动+充电电路、最顶上电源分配板。

**舵机选用**：和弦 = **MG996R**（慢、力矩大）；拨弦 = **MG90S**（快、力矩小）。

### 🎯 三条可直接照做的结论

| # | 结论 | 含义 |
|---|---|---|
| 1 | **不打孔、不改琴** | 靠"螺丝夹胶块"把三段夹在琴上 → 我们的"无损安装"是官方做法，不是妥协 |
| 2 | **12 = 6 弦 × 2 舵机**（不是 6 弦 × 2 品） | 一个舵机带一根齿条，**正转压 1 个点、反转压 1 个点**，2 个点/舵机 × 12 = 24 点 |
| 3 | 拨弦 6 舵机各管 1 弦 | 拨片**可前后滑移**再锁螺丝 → 找弦距就是调这个 |

## 二、代码里的"安装角度"口径（比图纸更硬）

### ★ 铁律：装齿轮/齿条之前，必须先给舵机通电回中 90°

官方固件写死的行为：

```cpp
// servo_driver.h
servo::init();   // 初始化所有舵机通道，回中 90°

// chord_engine.cpp :: reset_position()
for (int i = 0; i < 12; i++) servo::set_chord_by_idx(i, 90);  // 和弦 12 个全回 90°
// 拨弦归位到第一触发点（低点）
```

上位机同口径：`servo_controller.py` → `初始化: 和弦回中90, 拨弦归位`。

> **为什么这条能解决"齿条突出"**：齿轮齿条是在 **90° 中立位**啮合的。若在舵机停在别的角度时套上齿轮，齿条初位就跑偏，行程一头撞死、另一头够不着 —— 表现就是我们遇到的"齿条突出、装不进颈部"。行业口径也一致：**95% 的精度问题源于舵机臂未在中位锁定**。

### 零位偏移（每台机器独有，必须校准）

`config/servo_config.csv`：

```csv
null_offset,0,8,0,-2,0,-2,0,-5,0,-12,5,-5     # 12 个和弦舵机的零位偏移
strum_angles_1..6                            # 6 个拨弦舵机的 [低位角, 高位角]
```

### 压弦偏移的正负号 = 两排舵机是镜像装的

```csv
press_offset_1_*   +45 +50 +55 +60      ← 弦1/2/3 全为 正
press_offset_2_*   +42 +48 +53 +58
press_offset_3_*   +40 +46 +51 +56
press_offset_4_*   -38 -44 -49 -54      ← 弦4/5/6 全为 负
press_offset_5_*   -35 -41 -47 -52
press_offset_6_*   -32 -38 -44 -50
```

> **看出来了吧**：弦 1~3 正、弦 4~6 负 → **上下两排舵机的安装朝向相反（镜像）**。装反一个，那一弦的按压行程会整体反向，且不报错。

## 三、通道映射（V6.0，与我们的 XIAOZHI profile 对齐）

```cpp
// src/config/board_profiles.cpp
.chord_ch = { NONE, 15, 13, 11, 9, 7,   NONE, 16, 14, 12, 10, 8 },
.strum_ch = { 2, 4, 6, 1, 3, 5 },
.pwm_slot = { 0, 1 },   // 索引 0 → pwm[0]=GPIO40；索引 6 → pwm[1]=GPIO39
```

**弦序怎么定死的**：`chord_engine.cpp` 里 `k[6] = {0,2,4,6,8,10}` —— 第 x 弦占 `idx k[x]` 与 `k[x]+1`。
拆成人话（**这就是要照的那张表**）：

| 弦 | ch0（管品 1/2） | ch1（管品 3/4） | ch0 齿条 | ch1 齿条 |
|---|---|---|---|---|
| 第 1 弦 | **GPIO40 直驱**（不插 PCA） | **PCA 15** | 齿条1 | 齿条3 |
| 第 2 弦 | PCA 13 | PCA 11 | 齿条1 | 齿条3 |
| 第 3 弦 | PCA 9 | PCA 7 | 齿条1 | 齿条3 |
| 第 4 弦 | **GPIO39 直驱**（不插 PCA） | **PCA 16** | 齿条1 | 齿条3 |
| 第 5 弦 | PCA 14 | PCA 12 | 齿条1 | 齿条3 |
| 第 6 弦 | PCA 10 | PCA 8 | 齿条1 | 齿条3 |

拨弦 6 路（每弦 1 个）：

| 拨弦 index | 0 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|---|
| PCA 通道 | 2 | 4 | 6 | 1 | 3 | 5 |

**记忆法**：PCA **1~6 = 拨弦**，PCA **7~16 = 压弦**；弦 1 与弦 4 的 ch0 是唯二不走 PCA 的（GPIO40 / GPIO39 直驱）。
**PCA 16 路刚好用满、不重复**（固件自检 C16 卡这一条，抓过 3 次映射错误）。
⚠️ V5.1 与 V6.0 有 **8 处**映射不同，别混用。

## 四、齿条 1/2/3 分别对应什么（★ STL 几何实测 + 源码铁证）

### 4.1 源码铁证：每个舵机管哪两个品位

`esp32_platformio/src/chord_engine.cpp`：

```cpp
static const FretOffset FRET_OFFSETS[5] = {
    { 0,-1,  0,-1},   // 0品 (空弦) — 两通道均不偏移
    {+1, 0,  0,-1},   // 1品 — ch0 正向用 press[0]
    {-1, 1,  0,-1},   // 2品 — ch0 反向用 press[1]
    { 0,-1, +1, 2},   // 3品 — ch1 正向用 press[2]
    { 0,-1, -1, 3},   // 4品 — ch1 反向用 press[3]
};
```

⇒ **每根弦的两个舵机分工是写死的**：
- **ch0（品12组舵机）**：正转压 **1 品** / 反转压 **2 品**
- **ch1（品34组舵机）**：正转压 **3 品** / 反转压 **4 品**

这就是官方那句"每个舵机正反各压一个点"在代码里的实现。

### 4.2 齿条几何实测（解析二进制 STL 逐段统计，不是估的）

| 齿条 | 总长 | 齿杆段（与齿轮咬合） | **压弦头位置** |
|---|---|---|---|
| 齿条1 | 32mm | z 1.3~26.7（长 25.4） | **@28mm** |
| 齿条2 | 65mm | z 2.7~32.5（长 29.8） | **@61mm** |
| 齿条3 | 98mm | z 4.1~32.7（长 28.6） | **@95mm** |
| 齿轮 | ⌀20.9 × 4.5 | —— | 齿顶圆 ⌀20.9 |

**★ 关键：三根齿条的齿杆长度几乎一样（25~30mm），唯一区别是"压弦头伸多远"。** 三个压弦头位置等差 **33mm**。

### 4.3 33mm 是怎么来的 —— 一个品位间距 = 齿轮 180° 行程

| 量 | 值 |
|---|---|
| 齿轮转 180° 的弧长 | π × 20.9 / 2 = **32.8mm** |
| 吉他相邻品位间距（弦长按 650mm） | 1→2品 **34.3** / 2→3品 **32.7** / 3→4品 **31.3** |

两个 33 撞在一起不是巧合：**舵机 0°→180° 正好把压弦头挪过一个品位**。

### 4.4 ⇒ 对应关系

| 齿条 | 压弦头基准位 | 装的舵机 | 负责品位 |
|---|---|---|---|
| **齿条1** | 28mm | **ch0（品12组舵机）** | **品 1（静止）→ 品 2（转 33mm）** |
| 齿条2 | 61mm | 中间档 | 品 2 位置 |
| **齿条3** | 95mm | **ch1（品34组舵机）** | **品 3（静止）→ 品 4（转 33mm）** |

吉他标准品位位置：品1=36.4 / 品2=70.7 / 品3=103.4 / 品4=134.7mm —— 与齿条 32/65/98 各差 **5~8mm 的固定偏移**，整体吻合。

> ⚠️ **诚实边界**：齿条2（65mm）的去向官方没有文字说明 —— 它的压弦头位置正好等于"齿条1 转到位后的终点"，看起来是中间档 / 或补偿不同弦的安装深度。**现场 2 分钟判定法**：舵机先回中 90°，把齿条插进齿轮，看压弦头落在哪一品 —— 落在品 1 → 用齿条1；落在品 3 → 用齿条3。

## 五、装配顺序（我们照抄的 SOP）

1. **打印件埋热熔螺母**（官方 BOM 有 M3×3.5×4 热熔螺母）→ 否则螺丝锁不紧
2. **舵机通电回中 90°**（先只给信号+5V，不装负载）
3. 在 90° 状态**套齿轮、插齿条**，此时齿条应居中
4. 螺丝**对角分次**拧紧（不要一次锁死，会让舵机壳变形卡死齿）
5. **螺丝夹胶块**把三段夹到琴上 —— 琴体/琴颈零打孔
6. 上电扫一遍全 24 点，看有没有"该动的没动"（装反/装错齿条的会在这里露出来）

## 六、一句话总结

> **原项目的安装逻辑 = "三段夹持 + 12 舵机齿轮齿条正反压点 + 6 舵机可调拨片"，且必须在舵机回中 90° 的状态下装配齿轮齿条。** 我们的"齿条突出"大概率不是零件错，而是**装配时舵机不在 90° 中立位**，或**齿条长度选错**。
