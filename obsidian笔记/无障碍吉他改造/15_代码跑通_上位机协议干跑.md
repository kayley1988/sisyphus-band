## 三、帧格式（干跑验证的核心约定）
```
SYNC0(1B=AA) SYNC1(1B=55) LENGTH(1B) TYPE(1B) PAYLOAD(0~247B) CRC16(2B, 大端)
CRC 覆盖: TYPE + PAYLOAD
```
- `NORMAL_SERVO_BATCH`：18 个 0~180 角度，顺序 = [和弦0..11, 拨弦0..5]
- UART：**921600 波特**，泰山派 RX/TX ↔ ESP32-S3（小智板）
- 物理通道映射：`[PWM0, PCA15, PCA13, ..., PCA1, PCA4, PCA6, PCA8, PCA3, PCA5, PCA7]`

### ⚠️ 踩的两个坑（已修，记下来免得下次再踩）
1. **沙箱 safe-delete 批量删除保护**：PlatformIO 收尾清临时文件触发 `SAFE_DELETE_BULK_CONFIRM_REQUIRED`（阈值 50/轮次），把退出码翻成 1、链接被打断。→ 用 `dangerouslyDisableSandbox: true` 重跑绕开。
2. **中文路径下 MinGW 链接器失败**：仓库在 `E:\音乐\...`，`ld.exe` 写 `firmware.map` 报 `cannot open map file ... No such file or directory`（GCC 工具链对非 ASCII 路径写输出文件不友好）。→ 在 `platformio.ini` 加 `[platformio] build_dir = C:/pio_build/boyun_esp32`（纯英文），重跑即 SUCCESS。
