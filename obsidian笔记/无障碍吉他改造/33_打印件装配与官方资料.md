### 4.0b 尼龙烘干 SOP（必须做，10-07）

> **结论：必须烘，且是打印前必做项，不是可选项。** 尼龙（PA）吸湿速度极快——**拆封暴露在空气中 2~4 小时就吸够水分**，常温下放一夜基本等于报废。

**烘法（本机器 = 拓竹 P2S，用屏上自带的「烘干」功能，不用另买设备）**

> 📌 **P2S 确认支持热床烘干**（拓竹官方 wiki 明确列出：H 系列 / X 系列 / **P2S** / X2D 都有屏幕烘干流程；P1P / A1 / A1 mini 这类开放式机器没有）。热床范围 **35~110℃**，尼龙够用。

| 项 | 值 | 来源 |
|---|---|---|
| 耗材类型选 | **PA / 尼龙类** | |
| 热床温度 | **90℃**（官方 PA 系列给 90~100℃） | 取下限：第三方料盘 100℃ 有变形风险 |
| 时间 | **12 小时**（官方值；赶时间至少 8h） | 拓竹官方表 |
| 中途 | **翻面**（戴手套） | 官方要求，受热均匀 |
| 盖子 | 官方烘干盖（PA-CF/PC 打印）或用**包装盒/纸箱**代替 | 不盖则腔内温度上不去 |

**操作步骤（P2S 屏上）**

1. **先「退料」**——把耗材退出工具头，否则料在挤出机里软化会堵头
2. 清空热床上下区域 → 点「准备」，工具头/热床自动到预设位
3. 线盘**整盘平放**在打印板上，**盖上盖子**
4. 屏上选**烘干** → 选耗材类型 → 设 **90℃ / 12h** → **开始**
5. 中途**戴手套翻面**一次
6. 到时间 → 把热床设回 **0℃** → 不烫手再取出 → **趁热马上打**，打不完立即密封 + 干燥剂

> ☠️ **AMS 2 Pro 烘不了尼龙**：它只适配烘干温度 ≤65℃ 的耗材，官方表把 PA/PA-CF/PAHT-CF 全部标为**「不适配」**。别指望把线丢进 AMS 里自动烘——**只能用热床法**。（AMS HT 可以，85℃/12h，但你手上未必有。）

**判断烘没烘透（三条现场判据）**

| 现象 | 含义 |
|---|---|
| 喷嘴出料**噼啪响 / 冒白烟** | 水分汽化，**没烘透** |
| 挤出的料**有气泡、表面发白起雾** | 没烘透 |
| 层间**一掰就开裂 / 拨一下就断** | 没烘透（这是拨片头最致命的失效模式） |

**两条纪律**

- ⚠️ **别用厨房烤箱烘**：温度不准、有食物异味，而且家用烤箱温控波动 ±20°C，尼龙容易烤过头结块。
- ⚠️ **PETG 不用烘**（吸湿远低于尼龙），别把两种料一起丢进去。

### 4.1 拨片1 真实几何（10-07 切片实测，⚠️ 修正了解析 bug 后的数据）

> 🔧 **踩坑记录**：前几版数据是用 `_slice2_pick.py` 读的，该脚本**把 STL 法向量当成了第一个顶点**（`v[0:3]`），导致尺寸全错（X 被报成 -1..26、末端 2.52×5.02）。
> 二进制 STL 每面 50 字节 = **法向 3×f4 + 顶点 3×3×f4 + attr u2**，顶点是 `v[3:6] / v[6:9] / v[9:12]`。已修三个脚本。

| 段 | 长度 | 截面（厚 Y × 宽 Z） |
|---|---|---|
| **拨片杆** | x 0 .. 17 | **1.50 × 4.00 mm**（细扁条） |
| 过渡倒角 | x 17 .. 18 | 1.50×4.00 → 2.50×5.00 |
| **末端套筒** | x 18 .. 26 | **2.50 × 5.00 mm 外径**，内部有一个 **0.67 × 2.50 mm 的扁槽（深 8mm）** |

⇒ 拨片1 不是实心槌头，而是「**细杆 + 末端中空套筒**」，套筒正是给尼龙头插柄用的。

### 4.2 自制「拨片头（尼龙）」——已建模完成

> 文件：`E:\gt\自动吉他演奏装置\拨片头_尼龙.STL`（**与拨片1 同一坐标系，导入即自动对齐**）
> 生成器：`_gen_pick_head.py`（改参数可重生成）｜装配预览：`拨片1+头_装配预览.STL`

**设计**：不是套帽，而是「**插头**」——细柄插进拨片末端套筒的扁槽里，根部带限位肩，前面收成**尖头**（对应图片：白色拨片 + 黑色尼龙头，头是尖尖的）。

| 段 | 尺寸 | 说明 |
|---|---|---|
| 插入柄 | **0.42 × 2.24 mm**（厚 × 宽）× 8mm 深 | 插进拨片套筒的 0.67×2.50 扁槽，双边间隙约 **0.08mm** |
| 限位肩 | 4.6 × 7.1 mm，厚 1mm | 卡在拨片端面，防止插过头 |
| 过渡锥 + 尖头 | 外伸 **2.5mm** | 触弦端收成尖点 |
| 总长 | **10.50 mm**（x 18.0 .. 28.5） | 比原拨片长 2.5mm |
| 单件 | 0.056 cm³ / **0.07 g** | |

**配合检查**：洞 0.67×2.50 / 柄 0.42×2.24 → 双边间隙 Y=0.075mm、Z=0.080mm，可插入；网格 watertight（未配对边 0）。

**打印参数（尼龙）**：层高 **0.12** ｜ 3~4 墙 ｜ 250~270°C / 床 70~90°C ｜ 80°C 烘干 4~6h ｜ **一版排 12 个**（太小会层冷却不足塌陷）｜ 加 brim。
**打印姿态**：**柄朝下、尖头朝上** → 柄（细长）朝下立，**尖头朝上不需要支撑**；底面是限位肩，附着面积 4.6×7.1 足够。

> ⚠️ **柄很细（0.42mm 厚）**：打印后若插不进，用细砂纸轻轻打磨柄两侧；若太松，点 1 滴 502 固定。尼龙有弹性，上台拨弦时别让它转。

## 🧱 二、官方装配结构（作者原文整理）

> 「整体结构分为 **3 段**，分别是**和弦、主控、拨弦**，使用**螺丝夹住胶块**进行固定。」

### 1️⃣ 和弦段（12 个 MG996R）

- 按 **6 弦 × 4 品** 设计，共 **24 个按压点**；
- **每个舵机正转/反转各压一个点** → 12 个舵机覆盖 24 点；
- 传动方式：**齿轮 + 齿条**（对应我们的 `齿轮.STL` ×16、`齿条1/2/3.STL`）。
- ⇒ 对应打印件：`和弦舵机支架总装.STL`（130×139×92mm，最大件）+ `和弦支架底座.STL`

### 2️⃣ 拨弦段（6 个 MG90S）

- **每个舵机对应 1 根弦**；
- 有**拨片调节结构**，可前后调节拨片，用螺丝固定。
- ⇒ 对应打印件：`舵机固定架.STL` ×2、`拨片夹具.STL` ×8、`拨片1.STL`

### 3️⃣ 主控段（3 层结构）

| 层 | 内容 |
|---|---|
| 最底 | 泰山派主控板 |
| 中间 | 按钮 / 舵机驱动 / 充电电路 |
| 最顶 | 电源分配板 |
| 侧面 | **2 节 18650 并联**电池仓 |
| 顶部 | OLED 屏幕 + 音频小板 |

- ⇒ 对应打印件：`泰山派支架.STL`、`泰山派支架底座.STL`、`泰山派顶盖.STL`、`电池盖板.STL`、`屏幕音频固定板.STL`

## ⚡ 三、官方电源方案（★ 印证了我们的选型）

> 「电源板带锂电池保护，电池 **DCDC 升压到 5V**，一共**两路**：**一路 5A 给舵机**，**一路 2A 给主控和外设**，带电压检测、温度检测，和弦与拨弦各对应一路电流检测。」

| 路 | 规格 | 供什么 |
|---|---|---|
| 舵机路 | **5V / 5A**（TPS61088 升压：持续 4A、短暂 7A） | 18 路舵机 |
| 主控路 | 5V / 2A | 泰山派 + 外设 |

**结论**：作者整机只用 **2 节 18650 + 5A 升压** 就跑通了 18 路舵机。我们手上 **5V 10A 适配器 / S-100-5（20A）都是过剩的**——选型安全，不用再换。

（与 [[32_PCA9685与小智板接线]] 中"拨云实测峰值 3.12A、过流阈值 5.0A"完全吻合。）
