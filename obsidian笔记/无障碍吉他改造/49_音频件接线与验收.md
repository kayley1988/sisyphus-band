## 一、接线（照这张接）

**⭐ 实物照片定案（10-09，正反两面已拍）**：**音频只从板背左侧那排 2.54 焊盘引出，板上没有音频座子**。背面丝印自上而下：`GND · TX · RX · +5V · SPKN · SPKP · GND · MICP · GND · RTC · …`。正面那几只 GH1.25 座（`12V/GND` 供电等）均无音频 —— 此前记的「正面 4PIN GH1.25 音频座」**作废**（正面 4P 座应是调试串口，与背面 `GND/TX/RX/+5V` 同网络）。**焊背面焊盘 = 唯一入口，本方案没有分叉。**
**声卡**：`rockchiprk809co` / `fe410000.i2s-rk817-hifi`（RK809 = PMIC 内含 codec，走 RK817 驱动）。

| 背面焊盘（**照丝印认，别数行**） | 定义 | 接什么 |
|---|---|---|
| **MICP** | 麦克风正（MIC1P，带偏置） | 咪头**红线** |
| **MICP 紧邻的 GND**（它下面那颗） | 麦克风地 | 咪头**黑线** |
| **SPKP** | 喇叭 BTL 一端 | 喇叭一根 |
| **SPKN** | 喇叭 BTL 另一端 | 喇叭另一根 |

⚠️ **两个数行陷阱（照片核实出的真实排布）**：
- `SPKP` 再往上隔一颗就是 **+5V、TX、RX**（调试串口那组）——焊错到 **+5V** 上，咪头/喇叭直接见烟。
- **喇叭两端 = SPKP + SPKN，谁都不许碰 GND**。GND 就在旁边两颗（SPKP 与 MICP 中间那颗、MICP 下面那颗），顺手搭过去 = 烧功放（BTL，坑①）。

**实物判定（照片）**：咪头 = 模拟驻极体（红线正/黑线地，2P 白插头）；喇叭 = 8Ω 小功率（红黑 2P 白插头）。**Z 明确：这两个件是手边随便找的，不是泰山派配件。**

> ⚠️ **咪头选型红线（10-10 照片核实）**：必须是**两线制模拟驻极体咪头**（MICP + 地）。Z 手上另有一颗 **INMP441（I2S 数字 MEMS 咪，GND/VDD/SD/LR/WS/SCK 六脚圆板）—— 不能接 MICP/GND**：MICP 是 RK809 的**模拟**输入通路，INMP441 是数字器件，要 3.3V + I2S 时钟/数据，接它只能走 40PIN 的 I2S/PDM 脚并自建设备树声卡 = 固件级改造，违反本方案「不改固件」红线，**弃用**。若手上无模拟咪：¥1~2 买「驻极体咪头 带线」，或从旧耳机拆；**等货期可先焊喇叭（SPKP/SPKN），`--play` 验收不依赖咪头**。

⚠️ **板上没有音频座子可插（照片核实），一切"插"的路线全灭 → 定案如下：**

| 方案 | 要焊吗 | 成本 | 结论 |
|---|---|---|---|
| **C. 剪掉 2P 插头，直接焊板背面 4 个 2.54 焊盘** | 4 个焊点，**焊在板子本体** | 0 元 | ✅ **本方案（Z 已定，无需采购）**。官方双引出设计；唯一风险 = 焊盘被扯掉 → **必须做应力释放** |
| C+. 焊 1×4 的 2.54 排针上去，再用杜邦线插排针 | 焊 4 个点（焊排针） | 0 元（若手边有排针） | 更**可维护**：以后拔插动的是杜邦，不用反复碰焊点。缺点：占高、排针根部受力 |
| ~~A. 买 GH1.25-4P 线~~ | — | — | ❌ **作废（10-09 照片核实）**：板上没有音频座子，买了也没处插 |
| B. 官方音频小板 `LCKFB-TSPI-AUDIO-BOARD-A`（立创 C20598942，¥9.9） | 免焊（前提：小板座距与手上插头匹配） | ¥9.9 | 备选，等货 |

> ❌ **永远排除这条错路**：**杜邦线插不进 GH1.25 座**。座子是 **1.25mm 间距**，杜邦是 **2.54mm**，针太粗、间距不对，硬插必损座。要"插进板子"只能用 **GH1.25-4P 插头**。

### 方案 C 施工 SOP（焊板背 2.54 焊盘）

**焊接纪律（板载焊接的 4 条，违反=伤板）**：
1. **断电、拔线**，烙铁用**尖头**、焊锡 0.6mm、备助焊剂；**每点接触 ≤ 3 秒**（焊盘铜箔小，久烤必脱）。
2. **先给焊盘和线头各自预上锡**，再"回温贴合"送线——不要在焊盘上反复蹭。
3. **咪头怕热**：引脚根部垫镊子散热，接触时间尽量短（驻极体里是 FET，烤坏=永久失灵）。
4. **焊完立刻做应力释放**：线束用**热熔胶 / 扎带 / 无痕胶**固定在板面或壳体上，让**拉力落在固定点而不是焊点**。这一步比焊接本身更重要。

**步骤**：
1. **认焊盘（已按 10-09 背面照片核实）**：板背左侧焊盘列，丝印自上而下 `GND / TX / RX / +5V / SPKN / SPKP / GND / MICP / GND / RTC / …`。**只碰 4 颗：SPKN、SPKP、MICP、MICP 正下方那颗 GND**。落铁前用万用表蜂鸣挡把"丝印↔焊盘"逐颗复核一遍（防丝印与焊盘错位）。
2. 咪头、喇叭**剪掉 2P 插头**，剥皮 ~5mm、上锡。
3. 焊接：**脚1↔咪头红 / 脚2↔咪头黑 / 脚3↔喇叭一根 / 脚4↔喇叭另一根**。
4. 逐点热缩管绝缘（可选，但推荐）→ 打胶固定线束。
5. **通电前复查（万用表）**：① 脚3↔脚4 之间应测得喇叭直流电阻（几 Ω，**不是 0**），**任一端对 GND 必须开路**（BTL，坑①）；② 咪头红必须落脚 1（坑④）；③ 四根线互相不短路；④ 每根焊点轻拉不脱。
6. 上电 → 跑 `python3 tools/audio_check.py` 验收。

## 二、四个坑（背下来再动手）

| # | 坑 | 后果 / 做法 |
|---|---|---|
| ① | **脚3/4 是 BTL 桥接输出** | 喇叭两端分别接脚3、脚4，**任一端都不可接地**，否则烧功放 |
| ② | **插 HDMI 音频走 HDMI** | 外置喇叭不出声（我们不用 HDMI，无碍；但调试时别插着 HDMI 又疑惑） |
| ③ | **DAPM 三阀不推 → 喇叭死寂** | `Playback Route=SPK` → `Speaker Volume=80%` → `Left/Right DAC Switch=on` |
| ④ | **咪头无极性容错为 0** | 红线必须落脚 1(MIC1P)；接反录音极弱或全静音 |

## 三、验收 SOP（板子上线后一条命令）

```bash
# 板端（先 systemctl stop guitar.service 释放 GPIO/资源不必须，音频不冲突）
python3 tools/audio_check.py          # 四步全跑
python3 tools/audio_check.py --loopback   # 只验「喇叭→麦克风」声学耦合
```

| 步骤 | 判什么 | 通过标准 |
|---|---|---|
| `--list` | rk809 声卡节点起没起 | `aplay -l` 能看到 card；**看不到 = 设备树问题，接线白接** |
| `--unmute` | DAPM 三阀 | 各控制项设置成功 |
| `--play` | 喇叭出声 | 耳朵听到 1kHz「嘀」 |
| `--loopback` | 喇叭→麦克风声学耦合 | 放音期 RMS ≥ 静音基线 3× 且 >0.01；峰值≥0.98 会提示削顶 |

**录音参数**：`arecord -D hw:0,0 -f S16_LE -r 16000 -c 2`（回采用 16k，与 AI/ASR 链路一致）。
**放音采样率**：生成 48kHz（`guitar_tuner.py` 注释实证：**RK809 原生 48k；44100 会失败**）。

## 四、软件侧现状（核完代码的结论）

### 4.1 麦克风**不是新增功能，是补已有依赖** ⭐

代码里已经有三处在等这只咪头：

| 处 | 文件 | 用途 |
|---|---|---|
| ① | `screen_functions.py:395 / :450`（`measure_noise_floor` / `_pre_check_noise`） | **拨弦舵机自动校准的环境噪音预检**（pyaudio device 0 = rk809 codec）；无麦则返回 None，校准少一道保险 |

### 4.2 喇叭侧播放栈已就绪

`voice_player.play_prompt()` → `mpg123` / `ffplay`（三级回退到 `ffmpeg + aplay`）读 `src/guitarist/prompts/*.mp3`。
提示音通道 `trigger.guard.audio_hint`（默认关）+ `trigger_integration._make_audio_hint_channel()` **早已写好**。

**唯一缺口 = 两个 mp3 不存在** → 本次已补占位素材（短音，非语音）：

| 文件 | 时长 | 内容 | 音量 |
|---|---|---|---|
| `chord_ready.mp3` | 90ms | 880Hz 短叮（淡入淡出） | 0.28（刻意轻） |
| `her_timeout.mp3` | 400ms | 440→330Hz 双音下行 | 0.45 |

> 占位说明：先用**短音**而非语音 —— 零网络依赖、不抢戏、不干扰真弦发声。要换语音版（edge-tts 板端已装）说一声即可。

## 五、⚠️ 一个必须先拍板的设计问题

**`NOTIFY_READY` 在 `her_mode_guard.on_pressed()` 里每次压弦都发** → `audio_hint` 一开，`chord_ready` 会**每换一次和弦响一声**。

一首曲子换几十次和弦 = 响几十次。这对「就位提示」是好是坏，取决于她的需求：

| 方案 | 改动量 | 评价 |
|---|---|---|
| A. 就位用灯不用声（WS2812 六弦提示灯），**喇叭只做 timeout** | 0 行（`audio_hint` 通道里把 READY 分支去掉） | 最不抢戏；灯带本来就在一期清单（升级点②） |
| B. READY 声音加**节流**（同一和弦 N 秒内只响一次 / 只在首次就位响） | 小改 `her_mode_guard` | 兼顾"压弦无声"焦虑与安静 |
| C. 照现有逻辑每次都响 | 0 行 | 最直白，但频繁响可能烦 + 抢真弦的声音 |

**在 Z 拍板前，先不动这个逻辑** —— 素材已就位，拍板后改一行配置/代码即可。

## 六、红线（不变）

> 喇叭**只做 her 短提示音**（`chord_ready` / `her_timeout`），**禁止放音乐 / 伴奏 / 连续节拍音**。
> 理由：音必须由真弦发出，喇叭一放音乐 = 变成音乐盒，破坏"她重新成为演奏者"的答辩核心。

## 七、诚实边界

1. **未接线、未上板**：`aplay -l` 能否看到 rk809 仍是最大未知（官方文档只讲 Android，Ubuntu 22.04 固件的设备树待验）。
2. 占位提示音是**合成的正弦短音**，听感未经她本人试。
3. `audio_check.py` 的回采判定阈值（3× 基线）是首版经验值，现场噪音大时要调。
4. 麦克风的**用途**（除校准预检/自检外，是否参与拨弦检测喂教练引擎）是独立课题，本篇不展开。
5. ⚠️ **一处历史矛盾（存疑，上板一次即可定论）**：10-06 日志记过一句「麦克风实测电平 4899~5251 正常」，但**同一天也记了「板子没焊喇叭」**，且自检 `voice_loopback` 历史 4 次全失败。判断倾向：**那句电平是 MIC1P 空脚位读到的中值噪声**（≈5000 即中位，非真实拾音）。`audio_check.py --loopback` 一跑（放音期 RMS 是否显著高于静音基线）立刻分辨真伪。
