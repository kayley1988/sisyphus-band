## 🎯 需求（Z 口述）

歌要放到泰山派里 → 屏幕上要有**选歌**：**上下键选格，单击 SET 确定**。

### 三个设计决策（Z 拍板）

| 分叉 | 决定 |
|---|---|
| 怎么呼出 | **主界面短按「上」或「下」**直接弹（这两键在主界面本来就空闲） |
| 要不要"版本(图片源N)"层 | **不要**，自动挑能弹的版本 |
| 歌怎么上板 | 写**一键同步脚本** |

## ⚠️ 顺手挖出的一个真坑：每首歌只有一个版本是"能弹的"

一首歌在 `歌曲列表/` 下有多个「图片源N」（同一首谱的多个爬取来源），但**通常只有一个跑完了识谱流水线**。实测本地曲库：

| 歌曲 | 图片源1 | 图片源2 | 图片源3 |
|---|---|---|---|
| 后来 | ✅ | 空 | 空 |
| 晴天 | **空** | ✅ | 空 |

而旧代码 `esp32_player._find_csv_path()` **写死默认取「图片源1」** → 《晴天》从菜单点进去必然报「乐谱文件不存在」。上板曲库一多，这就是一个个隐形坑。

**收口**：新模块 `song_library.py` 逐首扫描、自动挑出真有 CSV 的版本（`输出结果（deepseek纠正版本）.csv` > `输出结果.csv`，与 esp32_player 优先级一致），选歌屏只列能弹的；没有 CSV 的进 `skipped` 清单（日志可见，屏上不出现）。

## 📐 选歌屏版式（240×240，黑底大字）

```
┌────────────────────────────────┐
│ 选 歌                  2/3     │ 标题亮黄 / 计数浅灰
│────────────────────────────────│
│ ▶ 晴天                         │ 5 行 × 32px
│   稻香                         │ 选中 = 亮红实心块 + 白字 + ">"
│   后来                         │ 未选 = 浅灰
│────────────────────────────────│
│   上/下 选    SET 弹    ESC 退  │
└────────────────────────────────┘
```

- 列表超过 5 行：以选中项为窗口中心滚动，右侧画 ▲▼ 小三角（用多边形画的，不赌字体有没有箭头字形）
- 歌名按**像素宽度**截断补「…」（中文按字符数截必错）
- **排序 = CSV 修改时间倒序**：刚转换好的歌排最前，不用翻到底找
- 空曲库给一句"曲库里还没有能弹的歌"，不留黑屏让人猜
- OLED（`GUITAR_USE_LCD=0`）有 128×64 兜底版式，同名接口

## 🔧 实现要点（6 条）

| # | 要点 | 说明 |
|---|---|---|
| 1 | `song_library.py` 纯逻辑可单测 | 扫描/挑版本/排序全部独立，PC 即可验证；`esp32_player._find_csv_path` 未动（选歌入口传的是显式版本） |
| 2 | 选歌屏是**独立状态** `STATE_SONG_PICK=12` | 独立按键处理块（与语音下载确认框同款写法），不去动主界面那套 ESC/双击逻辑 |
| 3 | 上/下**按住连发** | 0.45s 延时 + 0.12s 间隔——曲库上百首时一格一格按不现实 |
| 4 | `play_song(..., skip_confirm=True)` | 选歌屏入口跳过「确认/返回」框（版本已挑好，多一步反而碍事），演奏结束回**主界面**；菜单入口原行为不变 |
| 5 | 曲库**每次呼出现扫**，不缓存 | 几十首 <50ms；同步新歌上板后立刻可见 |
| 6 | 同步走 **tar → ASCII 路径** | adb 命令行传中文路径有编码风险；tar 内文件名 UTF-8 原样落盘。推送/解包/校验全走 `/data/local/tmp`（笔记 31"长脚本写成文件 push 上去跑"同款纪律） |

## 🐛 顺手修的既有 bug：`_flush_p` 蓝通道丢精度

RGB565 编码蓝通道写成 `b >> 5`（应为 `b >> 3`），8bit 蓝被砍到 3bit——**白色被画成淡黄、浅灰发黄**，所有走 `_flush_p` 的彩色页面（和弦面板/演奏主界面/选歌屏）都受影响。选歌屏的大面积浅灰字把它暴露了。已修（numpy 与纯 Python 两条路径都改），板上颜色会整体变正一点。

## ⚠️ 诚实说明已知边界

- **选歌屏只管"选和弹"**：`auto_play_show.py`（音浪演奏主界面，52 号）是独立进程，不归它管；要音浪+选歌合体得下一轮做
- **没有"版本"选择入口了**：自动挑的版本基本正确（每首歌通常只有一个能弹），但若某天一首歌真有两个可用版本且想指定，仍走 菜单→离线歌曲列表 的老路
- **演奏中不能呼出选歌**：先 ESC 停演奏，再上/下呼出
- **连发参数**（0.45s/0.12s）是按手感估的，上板试了不顺再调
- 曲库扫描按目录名判断，**不校验 CSV 内容**——转换半途而废的歌（有 CSV 但只有前几个小节）照样会列出来
- 板端依赖板上已有 `歌曲列表/` 目录约定与 `song_library.py`（同步脚本推代码时别漏）
