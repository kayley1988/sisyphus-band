## 〇、一句话定位

**泰山派 = 大脑（想），ESP32-S3 小智板 = 小脑（动）。**
《拨云》整套代码**原生就是为泰山派写的**——所以泰山派不是从零写，而是"部署 + 做我们的增量改造"。

```
┌─────────────────────────┐   UART 921600    ┌──────────────────────────┐
│  泰山派 RK3566 (Ubuntu)  │ ───────────────→ │  ESP32-S3 小智板         │
│  Python 主程序 main.py   │   二进制帧协议    │  FreeRTOS 固件           │
│  · 演奏引擎（谱面时序）  │  ←─────────────── │  · PCA9685→16路 PWM     │
│  · 菜单 / OLED 界面      │   电流回传        │  · LEDC→2路 PWM          │
│  · 电流校准算法          │                  │  · ADC 电流采样          │
│  · WiFi / 电源监控       │                  │   = 18 个舵机硬实时驱动  │
│  · 触发源（自动 / 她的手）│                  └──────────┬───────────────┘
│  · OCR 乐谱 / AI 语音    │                              ↓
│    （彩蛋，可不要）       │                      12×MG996R 压弦
└─────────────────────────┘                      6×MG90S 拨弦 → 真琴响
```

## 一、泰山派上到底跑什么（已确认）

主程序入口：`src/guitarist/main.py`（systemd 服务管开机自启）。

`main.py` 顶层只导入这些核心模块——**全部是主线必需**：

| 模块 | 职责 |
|---|---|
| `state` | 全局状态机 |
| `hardware` | GPIO / I2C / OLED / 按键集中管理（`board.GPIO3_*`、`I2C2`→SSD1306） |
| `oled_renderer` / `screens` | OLED 128×64 显示 |
| `menu_system` | 菜单（UP/DOWN/SET/ESC 四键） |
| `button_handler` | 按键检测线程 |
| `wifi_manager` | WiFi |
| `power_monitor` | 电源/电流监控（校准用） |
| `esp32_player` / `frame_*` | **UART 二进制协议 → 小脑**（我们已经干跑验证过） |

| easyocr / paddleocr | 乐谱 OCR | ❌ 不要（彩蛋，且吃 NPU/内存） |

| sherpa-onnx / vosk / webrtcvad / sounddevice / PyAudio | 语音识别/唤醒 | ❌ 不要（AI 语音正是我们拆掉的） |
| openai / edge-tts | LLM/语音合成 | ❌ 不要 |
| flask | Web 服务 | ⬜ 可选（logs_api），主线不急需 |

**裁剪后核心依赖（已另存 `E:\音乐\拨云_开源参考\requirements_core.txt`）：**
numpy / scipy / protobuf / PyYAML / python-dotenv / pandas / loguru / psutil / tqdm / pyserial / python-periphery / spidev / Adafruit-Blinka / adafruit-circuitpython-ssd1306 / Adafruit-SSD1306 / Pillow / requests

## 三、部署步骤（板子到货后执行）

1. **刷系统**：立创官方 Ubuntu 20.04.6 LTS（aarch64）镜像 → 烧进 64G 卡。⚠️ 下单前已让问卖家"能否刷官方镜像"，确认能刷才拍（8G 魔改版）。
2. **开 swap**：`install_deps.sh` 的 Phase 0.5 会建 swap 防 OOM；我们虽然裁剪了，仍建议留 2G swap 稳妥。
3. **装核心依赖**：`sudo pip3 install -r requirements_core.txt`（跳过全家桶）。
4. **初始化配置**：`config.yaml` 从模板复制（脚本 Phase 2.6 做）。
5. **跑主程序**：`python3 main.py` —— 验证 OLED 亮、菜单出、串口能打开。
6. **开机自启**：`autostart_manager` 用 systemd 管 main.py（黑客松演示免手动起）。

> 原版 `tools/install_deps.sh` 是 Phase 0~4 全家桶安装，我们**不用它**，改用上面的裁剪流程。

## 四、我们的代码改造（增量，也是答辩亮点）🔧

### 4.1 触发源抽象层（核心改造）
现状：《拨云》触发 = 菜单选曲 → 谱面定时器自动演奏（"自动吉他手"）。
我们要加：**她的手 = 唯一触发源**。改造点：
- 在 `state` / 演奏引擎层抽象出 `TriggerSource` 接口：`ScoreTimerTrigger`（原自动）与 `TouchStripTrigger`（她的触摸条）二选一。
- 答辩主场景走 `TouchStripTrigger`；自动演奏降级为调试工具 + 彩蛋。
- **红线**：她没有动作时，一个音都不响（触摸条点动模式天然满足，见采购笔记）。

### 4.2 触摸条 GPIO（TTP223 ×N）
- 采购了 TTP223×10，接泰山派 **空闲 GPIO**（避开已用的 GPIO3_A1~A4 / B0~B3 按键 + I2C2）。
- 改 `hardware.py`：新增 `init_touch_strip()`，把 N 路 TTP223 注册为数字输入，每个键 = 一个和弦/单音触发。
- 纵向紧凑排布（总宽 ≤8cm），规避她手指跨度缺陷。

### 4.3 可选：禁用 AI 自启
若 main.py 任何路径懒加载 `ai/` 或 `score_recognition` 并自启，需加开关关掉，避免无谓占内存。主线不依赖它们。

### 9.4 三条硬规则落地情况
① **触发权在人**：`TouchStripTrigger` 用 TTP223 点动模式（按下=高=压弦，松开=低=松弦），由硬件电平直接保证；`hold_chord`/`release_chord` 由她的手触发
② **右手零改造**：`PLAY_CHORD` 只压弦不拨弦（拨弦通道恒 idle），她右手拨
③ **随时能停**：松开触摸即发 release 帧（开放弦零位），一个音都不响
④ **自动只调试**：`ScoreTimerTrigger` 是调试/彩蛋，主舞台是 `TouchStripTrigger`
